# Roman Numeral Drill

A practice page for identifying the key and the Roman numeral of a four-voice chord on a grand staff.

Each example shows the mode, a key signature, and one diatonic triad or seventh chord (augmented triads and major seventh chords are excluded). Enter the key and the Roman numeral with its figure, then press **Check**. A green check or red X appears next to each answer. When both are right, **Next** loads a new example.

Everything runs in the browser from `index.html`. Notation is drawn with [VexFlow](https://www.vexflow.com/).
